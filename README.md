# Sweet Bloom — เว็บไซต์รีวิวร้าน

เว็บไซต์ตัวอย่างสไตล์ชมพูพาสเทล ใช้งานได้บนมือถือและเดสก์ท็อป มีหน้ารีวิวและหลังบ้านสำหรับปรับแต่งชื่อร้าน ข้อความสถานะ รูปโปรไฟล์/ปกหลัง สถานะเปิดร้าน เพลง YouTube และช่องทางติดต่อ

## เปิดดูเว็บไซต์

เปิด `index.html` ด้วยเบราว์เซอร์ หรือเปิดด้วย local web server เช่น VS Code Live Server

## เริ่มต้นใช้งาน

1. กด **หลังบ้าน** แล้วตั้งรหัสผ่านครั้งแรก (อย่างน้อย 8 ตัวอักษร)
2. ปรับข้อมูลร้านและกดบันทึก
3. ลูกค้าสามารถเขียนรีวิวและแนบภาพได้
4. ใส่ลิงก์ YouTube แล้วกดเล่นเพลง (เบราว์เซอร์อาจต้องให้ผู้ใช้กดเล่นก่อน)

## ข้อจำกัดสำคัญ

รุ่นนี้เป็นเว็บ static สำหรับทดลอง ข้อมูล รีวิว รูป และรหัสผ่านเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ได้แชร์ข้ามอุปกรณ์ และไม่ใช่ระบบยืนยันตัวตนที่ปลอดภัยสำหรับหลังบ้านจริง การตั้งรหัสผ่านครั้งเดียวจึงมีผลเฉพาะเบราว์เซอร์นี้ หากต้องการเปิดร้านจริงหรือให้หลายคนเห็นรีวิว ควรต่อ backend/database และระบบ authentication ก่อนเผยแพร่

รูปที่อัปโหลดจำกัด 2 MB ต่อไฟล์เพื่อป้องกันพื้นที่เบราว์เซอร์เต็ม
